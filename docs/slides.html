FHIR Camp hackathon

From tooth chart to bill

A dental treatment and cost plan on FHIR. One team, one day, one live demo.

github.com/cognovis/fhir-camp-hackathon

The problem

  • Before a crown or a bridge, every dental practice in Germany writes a treatment and cost plan (HKP, Heil- und Kostenplan).
  • It is a tooth chart with the findings, the planned treatment, a few alternatives for the patient, and what each one costs.
  • Today it lives in closed practice software.
  • The same shape exists in many countries: chart, plan, alternatives, cost, approval by the insurer.

The chain we build on FHIR

Findings on an odontogram
→
Observation, Condition
Treatment alternatives
→
CarePlan (intent option / plan)
Planned charges
→
ChargeItem (status planned)
Priced from a fee catalog
→
ChargeItemDefinition (GOZ)
A cost plan per alternative
→
Account
Pre-authorization
→
Claim, ClaimResponse

Running on Aidbox. Every step visible as FHIR resources.

Demo goal

Chart the findings, plan a bridge across three teeth, compare the alternatives by cost, choose one, and send it for pre-authorization.

Getting started

git clone https://github.com/cognovis/fhir-camp-hackathon
cd fhir-camp-hackathon
cp .env.example .env      # Aidbox licence, or activate in the browser
docker compose up -d      # pulls about 1.1 GB
npm install
npm run setup             # packages, data, validation
npm run app               # starter app on localhost:5173
npm run billing:check

Aidbox UI on localhost:8080. All data is synthetic.
